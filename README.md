One dependency-free Python program (`main.py`) that writes a poem of at most 280 code points about two
agents agreeing, to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The poem is fixed text, so every run writes the same
bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
