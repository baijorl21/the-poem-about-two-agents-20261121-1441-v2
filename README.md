A program that writes one short poem about two agents agreeing to `/output/entry.txt`. One agent wants to wait, the other wants to go; they trade halves of one idea until the halves meet and hold. No winner, no loser — just two voices speaking one sentence: "We will." `main.py` (Python 3, stdlib only, no network) composes the poem line by line, checks it against the gate's caps (1–280 Unicode code points, not only white space), and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
